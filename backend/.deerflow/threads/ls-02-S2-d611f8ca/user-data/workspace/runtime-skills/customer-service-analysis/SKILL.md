# 客服对话分析技能

## 触发条件
当用户提供客服对话文本并要求分析时，立即使用本技能。

## 工作流程
1. **接收客服对话文本**：获取用户提供的客服对话内容
2. **分析提取用户诉求**：识别并总结用户的核心问题或需求
3. **判断用户情绪状态**：评估用户情绪（如愤怒、焦虑、困惑、平静等）
4. **分类问题类型**：将问题归类（如技术故障、退款问题、账户异常、服务中断等）
5. **生成建议回复**：提供专业、同理心的建议回复方案
6. **判断是否需要升级处理**：评估问题是否需要升级到高级客服或技术团队

## 输出格式
严格按照以下5部分结构输出分析结果：

### 1. 用户诉求
- 简要总结用户的核心问题

### 2. 情绪判断
- 判断用户情绪状态及强度
- 提供情绪依据

### 3. 问题分类
- 问题类型归类
- 可能涉及的业务模块

### 4. 建议回复
- 提供专业、同理心的回复建议
- 包含具体解决步骤

### 5. 是否需要升级处理
- 是/否
- 升级理由（如果需要）

## 示例
**输入**："我昨天买的会员今天就不能用了，你们到底怎么回事？"

**输出**：
### 1. 用户诉求
用户反映昨日购买的会员服务今日无法正常使用，要求解释原因并解决问题。

### 2. 情绪判断
- 情绪：愤怒、失望
- 强度：高
- 依据：使用"到底怎么回事"等强烈质问语气，表达对服务中断的不满

### 3. 问题分类
- 类型：服务中断/技术故障
- 业务模块：会员服务、支付系统

### 4. 建议回复
"非常抱歉给您带来了不好的体验。我们理解您对会员服务突然无法使用的 frustration。请提供您的账户信息或订单号，我们将立即为您检查会员状态和系统记录。同时，我们会为您延长会员有效期作为补偿。"

### 5. 是否需要升级处理
- 是
- 理由：涉及付费服务中断，需要技术团队排查系统故障并优先处理

## 验证要点
1. 确保输出包含所有5个部分
2. 用户诉求应简洁准确
3. 情绪判断需基于对话文本证据
4. 问题分类应合理明确
5. 建议回复需专业且具同理心
6. 升级判断需基于问题严重性
