# 用户反馈分析技能

当用户提供一段用户反馈文本并要求按照固定七步流程分析时，立即使用本技能。

## 固定分析流程

1. **反馈摘要**
   - 用一句话简洁概括反馈的核心内容
   - 提取用户反馈中的关键痛点

2. **问题归因**
   - 分析导致用户反馈问题的根本原因
   - 从产品设计、用户体验、技术实现等角度分析

3. **影响用户类型**
   - 识别受此问题影响的用户群体
   - 分析用户特征（如新用户、老用户、特定角色等）

4. **建议优先级**
   - 评估问题的紧急程度和重要性
   - 使用 P0/P1/P2/P3 或高/中/低优先级标注

5. **推荐处理方案**
   - 提出具体、可操作的改进建议
   - 建议应针对问题归因，具有可行性

6. **是否进入版本迭代**
   - 判断该问题是否需要安排到产品版本迭代计划中
   - 给出理由和预计时间建议

7. **需要补充的数据**
   - 列出需要进一步收集的信息或数据
   - 包括用户访谈、数据分析、竞品调研等建议

## 输出格式

输出必须是结构化的 Markdown 格式，包含以上七个部分，每个部分都应有清晰的标题和内容。

## 使用示例

**输入：**
用户反馈："很多商家说活动创建页字段太多，第一次配置优惠券规则时很难理解，提交前也看不到校验提示。"

**输出：**
### 1. 反馈摘要
[摘要内容]

### 2. 问题归因
[归因分析]

### 3. 影响用户类型
[用户类型分析]

### 4. 建议优先级
[优先级评估]

### 5. 推荐处理方案
[处理方案建议]

### 6. 是否进入版本迭代
[迭代建议]

### 7. 需要补充的数据
[补充数据建议]

## 注意事项

- 保持分析客观，基于用户反馈内容
- 避免过度解读，聚焦反馈中的具体问题
- 建议应具有可操作性，避免空泛
- 优先考虑用户的实际使用场景
