# 运营方案评审技能

## 使用场景
当用户提供运营方案草稿文本并要求按固定流程进行评审时，立即使用本技能。典型的触发场景包括：
- 用户提供运营方案草稿并要求“评审”
- 用户提供运营方案并要求“按六步流程分析”
- 用户提供运营活动计划并要求“评估实施可行性”
- 用户提供激励计划、推广方案、资源配置方案等运营相关内容

## 工作流程
本技能强制执行以下六步评审流程：

### 1. 方案摘要
用一句话概括核心方案，明确要解决的主要问题。

### 2. 目标用户价值
分析方案对目标用户的核心价值、使用场景、用户群体和预期效果。

### 3. 核心机制拆解
将方案拆解为具体运营机制、规则配置、执行流程和关键指标。

### 4. 实施风险
识别运营、资源、时间、合规、执行等方面的潜在风险。

### 5. MVP范围
定义最小可行运营范围，建议优先级和迭代计划。

### 6. 给执行团队的落地建议
提供运营执行、资源配置、培训、监控、优化等具体建议。

## 输入输出
- **输入**：运营方案草稿文本
- **输出**：结构化的六步评审报告，每个步骤独立章节

## 注意事项
- 专注于运营方案的业务层面，而非技术实现细节
- 确保建议切实可行，考虑实际执行资源
- 风险分析需包含可预见的运营风险和应对措施
- MVP范围建议应明确优先级和时间线
