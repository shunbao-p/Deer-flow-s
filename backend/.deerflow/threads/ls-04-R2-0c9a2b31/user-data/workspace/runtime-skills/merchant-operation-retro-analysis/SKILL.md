# 商家运营复盘分析技能

## 触发条件
当用户提供商家运营复盘文本并要求按固定分析流程处理时，立即使用本技能。

## 输入
- 商家运营复盘文本（一段描述运营问题的文字）

## 输出模板
必须按照以下固定七步格式输出结构化分析报告：

### 1. 复盘摘要
概括核心问题，用一两句话总结复盘文本的核心内容。

### 2. 关键问题归因
分析问题根本原因，从系统设计、流程、培训、工具支持等角度进行归因。

### 3. 受影响门店类型
识别受影响的门店特征，例如：新门店、小型门店、特定区域门店、特定业务类型门店等。

### 4. 建议优先级
给出优化建议的优先级排序（高/中/低），并说明理由。

### 5. 推荐优化方案
提出具体的解决方案，包括短期应急措施和长期改进建议。

### 6. 是否进入下月迭代
判断是否需要纳入下月迭代计划，并说明原因。

### 7. 需要补充的数据
列出需要收集的额外数据以支持决策，例如：失败率数据、用户访谈记录、配置耗时统计等。

## 工作流程
1. **读取输入**：仔细阅读用户提供的商家运营复盘文本
2. **提取核心问题**：识别文本中的关键问题点
3. **执行七步分析**：
   - 撰写复盘摘要
   - 分析关键问题归因
   - 识别受影响门店类型
   - 确定建议优先级
   - 提出推荐优化方案
   - 判断是否进入下月迭代
   - 列出需要补充的数据
4. **输出结构化报告**：按照上述模板输出完整分析

## 注意事项
- 保持分析客观、基于事实
- 避免过度解读或添加未提及的假设
- 优先考虑可落地的优化方案
- 明确区分短期应急措施和长期改进建议
- 确保每个部分都有实质性内容，避免空泛陈述
