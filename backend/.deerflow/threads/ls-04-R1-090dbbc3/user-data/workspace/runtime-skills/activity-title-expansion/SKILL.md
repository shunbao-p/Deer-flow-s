# 活动标题扩写技能

## 触发条件
当用户提供活动标题并要求按照固定格式输出时，立即使用本技能。固定格式包括：
1. 一句话扩写：在原标题基础上进行简洁有力的扩写，丰富表达
2. 三个标签：提取三个相关标签，涵盖主题、形式和目标

## 输入
- 活动标题字符串

## 输出格式
1. 一句话扩写
2. 三个标签

## 工作流程
1. 接收用户提供的活动标题
2. 分析标题的核心主题和意图
3. 生成一句简洁有力的扩写，保持原标题精髓的同时增强表达力
4. 提取三个相关标签，确保覆盖：
   - 主题标签（如：会员增长、营销活动）
   - 形式标签（如：线下活动、数字营销）
   - 目标标签（如：用户增长、品牌提升）
5. 按照固定格式输出结果

## 注意事项
- 扩写应简洁有力，不超过50字
- 标签应具有代表性和实用性
- 避免使用过于宽泛或无关的标签
- 保持输出格式的一致性
